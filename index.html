    3 Grammar transformation

    Original grammar ambiguous

    S → if E then S
S → if E then S else S
S → other

    For if E then if E then other else other this grammar gives two parse trees.

    Transformed grammar unambiguous

    S → M | U
M → if E then M else M | other
U → if E then S | if E then M else U

    The same strings, but every string has exactly one parse tree.

    How the transformation works

    1. Split statements into two kinds. M matched: every if has its own else (or the statement is just other). U unmatched: some if is still waiting for an else.
    2. Restrict what may stand between then and else. In M → if E then M else M the then-part must be M. An if without else can never appear there.
    3. Let unmatched ifs absorb the else. U → if E then M else U and U → if E then S describe an if that is still open, so the else is always paired with the nearest open if.

    Result: the only way to read if a if b x else y is "the else belongs to if b" – exactly what C and Java do.
